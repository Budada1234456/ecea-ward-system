# 中国节能协会创新奖申报系统

根据 `节能奖填报材料` 中的 2026 年申报书、填写说明、奖励办法和已填样例构建。

## 已实现

- 项目中心首页、年度/状态/名称筛选
- 可切换的公告中心、常见问题和参考资料页面
- 依据 2026 正式材料整理的时间安排、资格条件、提交规范和联系方式
- 新建申报材料时选择三类子奖项、申报渠道和申报/推荐单位
- SQLite 后端数据库与多项目并行申报
- 账号注册、登录、退出、找回与重置密码
- HttpOnly 会话、用户项目归属和跨账号访问隔离
- 新建、复制、继续填写、归档申报项目
- 每个项目独立自动保存、本地草稿兜底、浏览器返回导航、完整度和状态管理
- 参照现有科技奖励申报系统的工作台布局和交互
- 节能减排科技进步奖、技术发明奖基础字段
- 完成人、完成单位、学科分类和项目来源动态填写
- 申报书完整章节导航及首批可编辑章节
- SQLite 后端自动保存，项目之间数据相互隔离
- PDF 文本提取、扫描首页中英文离线 OCR、字段识别、置信度展示和人工确认
- “从零在线填报”和“导入完整材料”两种申报方式
- 原始签章合并版 PDF 持久化、查看和一键原样导出
- 四类附件上传、真实页数统计、40 页硬限制、查看、下载和删除
- 提交前必填校验及“形式审查”状态流转
- 覆盖全部表单章节的 A4 预览和完整 PDF 导出
- 桌面端和移动端适配

## 本地运行

开发模式：

```powershell
npm install
npm run dev
```

访问 `http://127.0.0.1:5173`。

生产模式：

```powershell
npm run build
npm start
```

访问 `http://127.0.0.1:4174`。

项目需要 Node.js 22.5 或更高版本。当前服务器上的启动脚本也会自动使用可用的 VS Code Server Node 运行时。

初始管理员账号为 `admin`。密码不要写入项目文件，首次公网发布前必须设置独立强密码。本地环境如需临时显示找回密码重置码，可显式设置 `ALLOW_INSECURE_PASSWORD_RESET=true`；公网环境不得启用此选项。

服务运行时可执行完整浏览器验收：

```powershell
npm run test:e2e
```

## PDF 识别说明

本机需能执行 `pdftotext`、`pdfinfo` 和 `pdftoppm`。当前最多分析 500 页，可识别中英文项目名称、联系人、电话、邮箱、起止日期、主要完成人、主要完成单位、第一申报单位，以及项目简介、立项背景、详细技术内容、创新点、同类技术比较、应用、经济效益和社会效益。人员和单位会优先从带编号的附件目录提取，并使用表单章节作为兜底。识别结果按字段展示来源与置信度，默认全部勾选并可一键回填对应浏览器表单。

当首页缺少文本层时，系统会使用随项目安装的简体中文离线 OCR 语言包识别基本信息页；长篇正文仍优先使用 PDF 文本层，以兼顾速度和段落准确性。项目数据保存在 `data/award-system.db`，附件和原始签章 PDF 保存在 `data/files/`。

运行案例 PDF 回归测试：

```powershell
npm run test:extract
```

## 其他电脑访问

默认 `npm start` 只监听 `127.0.0.1`，只能从本机访问。

同一局域网内临时协作可运行：

```powershell
npm run build
npm run start:lan
```

其他电脑随后通过 `http://本机局域网IP:4174` 访问。主机需要保持开机，并在 Windows 防火墙中仅对可信的“专用网络”放行 TCP 4174 端口。

## 公网访问

当前服务器可通过 Cloudflare Quick Tunnel 临时 HTTPS 隧道发布，不需要开放路由器端口：

```powershell
npm run build
npm run start:public
```

启动成功后，终端会显示 `https://...trycloudflare.com` 公网地址，同时写入 `data/public-url.txt`。PDF 上传后会在服务器后台解析，网页自动等待并显示识别结果，避免大文件和长时任务被公网代理中断。该地址可从任意互联网网络访问，但本机必须保持开机联网；免费临时地址在隧道重启后会变化，且第三方临时隧道不提供生产可用性保证。启动前需确保 `cloudflared` 已安装并可在 `PATH` 中执行。

本服务器已配置为当前用户的后台服务。常用维护命令：

```powershell
# 查看当前公网地址
cat data/public-url.txt

# 查看运行状态和最近日志
systemctl --user status award-system.service
journalctl --user -u award-system.service -n 100 --no-pager

# 修改代码并重新构建后重启服务（重启会生成新地址）
npm run build
systemctl --user restart award-system.service
```

当前版本已具备账号会话、项目所有权隔离、HTTPS Cookie 和认证接口限流。低并发试运行可继续使用服务器上的 SQLite；多人高并发正式使用建议迁移到 PostgreSQL，并配置固定域名、邮件或短信重置、附件恶意文件扫描以及数据库和附件异机备份。所有浏览器提交的数据都会写入部署服务器的中央数据库，而不是各填报人的电脑。
